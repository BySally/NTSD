## Description (EN)

# Nuclear Tech: Second Dawn

**The next industrial era begins here.**

**Nuclear Tech: Second Dawn (NTSD)** is an independent technology-focused modpack for **Minecraft 1.20.1 Forge**, created by **BySally**. Built around **HBM Nuclear Tech Mod: Continuum**, NTSD brings together nuclear engineering, heavy industry, automation, and the promise of space exploration.

### What to expect

- **Nuclear engineering:** explore reactors, fuel processing, radiation, and interconnected HBM technologies.
- **Industry and automation:** scale up production with logistics and automation tools, including Applied Energistics 2, ProjectRed, and CC: Tweaked where included in the verified release.
- **Quest-driven progression:** follow an adapted quest experience based on **Nuclear Tech: New Horizons (NTNH)**.
- **Space and exploration:** advance into space-related technology with the project's Continuum Space integration.

### Development status

NTSD is in **alpha development**. The first public build is not available until compatibility and clean-install testing are complete. Features, performance, and configuration may change between alpha versions.

### Installation

Install the official modpack through the CurseForge app once the project and release are approved. **Minecraft Java Edition is required.** For server hosting, use the matching **Server Pack** attached to the relevant CurseForge modpack file once published. Do not mix server and client versions.

## Описание (RU)

# Nuclear Tech: Second Dawn

**Новая эра индустриального Minecraft.**

**Nuclear Tech: Second Dawn (NTSD)** — независимая технологическая сборка для **Minecraft 1.20.1 Forge**, созданная **BySally**. Её основа — **HBM Nuclear Tech Mod: Continuum**, ядерная энергетика, промышленное производство, автоматизация и космические технологии.

### Основные направления

- **Ядерные технологии:** реакторы, топливные цепочки, радиация и оборудование HBM.
- **Автоматизация:** развитие заводов, логистики и сложных производственных систем.
- **Квесты:** адаптированная прогрессия на основе **Nuclear Tech: New Horizons (NTNH)**.
- **Космос:** развитие технологий Continuum Space.

### Статус разработки

NTSD находится на стадии **альфа-разработки**. Публичный релиз появится после проверки установки, запуска, совместимости модов и работы серверной сборки.
