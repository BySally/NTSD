## NTSD presentation resources

**BySally — concept, prompting, selection and project direction. Provenance: AI-generated with OpenAI.** The owner states that the NTSD illustrations, pixel icons and MP4 animations were generated for this project with ChatGPT; animations were assembled from those images with further processing. This is an owner-supplied provenance statement, not proof of exclusive copyright or a claim that OpenAI endorses this pack.

The NTSD questbook background, loading frames, orbital video and icon originate in the owner-supplied AI-generated materials. Original NTNH themes, sound and text are credited separately; they are not reclassified as NTSD originals.

This GitHub alpha release omits the mixed Minecraft/TXLoader font, old Improving Minecraft texture copies, 14 old quest icon pixel copies and optional custom third-party translation overlays. Its questbook font is constructed in memory from installed Minecraft resources by Core CF4; Press Start 2P is not included. Runtime game texture references are retained. Quest IDs, quest text, rewards and completion conditions remain unchanged. The original working alpha.6 is unchanged.

The PNC 6.0.23 Drone Interface JSON correction is integrated into Core, with desht / MineMaarten attribution and GPL-3.0-only notice. The same recipe ID, conditions, shape and output are retained. Code/asset licenses are independent: no blanket All Rights Reserved is applied, and no new distribution restrictions are published by this preparation.
