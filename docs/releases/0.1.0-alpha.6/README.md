These documents were moved from the release Assets without changing either game
ZIP. The client remains a CurseForge App import package (118 official downloads,
four bundled JARs, 122 JARs after installation). The 8.66 MB server archive remains
a **bootstrap installer**, requiring Java 17, Python 3.10+, internet and the matching
installed client. It is not a FULL/offline server distribution.

The installation/testing statements describe the published installers, not a later
private standalone-server candidate. No new gameplay test or archive rebuild is
claimed by this documentation cleanup. Existing per-component notices remain in
the unchanged ZIPs. CF3's separate source tag remains available in NTSD-Core.
