# Установка Nuclear Tech: Second Dawn 0.1.0-alpha.6

Автор и сопровождающий: BySally. Minecraft **1.20.1**, **Forge 47.4.28**, **Java 17**. Это первый публичный предварительный релиз; полный перенос NTNH ещё не закончен. Перед обновлением сохранений сделайте отдельную резервную копию.

## Клиент — рекомендуемый и проверяемый путь: CurseForge App

1. Скачайте `NTSD-0.1.0-alpha.6-client.zip` из GitHub Releases. **Не распаковывайте** его в обычную папку mods.
2. Установите/откройте [официальный CurseForge App](https://www.curseforge.com/download/app), выберите Minecraft → My Modpacks → Import → Import from ZIP. Выберите скачанный ZIP. Если App покажет предупреждение о файлах вне каталога CurseForge, отметьте подтверждение и выберите **All Files**: это необходимые настройки, квесты и собственные компоненты NTSD. Вариант **CurseForge Files Only** пропустит их. Это локальный импорт, поиск публичного модпака в каталоге CurseForge не требуется.
3. Дождитесь завершения загрузки всех модов. 118 файлов App получает у авторов; Core CF4, Early Loading, Menu Background и разрешённый неизменённый CC:Tweaked уже внутри overrides. Одобрение трёх проектов NTSD на CurseForge для этого пути не требуется.
4. В настройках профиля выделите около **6–8 ГБ** RAM, оставляя память системе. Используйте Java 17. Не обновляйте версии автоматически.
5. Нажмите Play, войдите в официальный Minecraft Launcher своей учётной записью с купленной Java Edition и запустите профиль. Авторизация, аккаунт и игра в архив не входят.
6. Создайте **новый мир**. Книга квестов открывается клавишей **`** (клавиша слева от 1; при конфликте проверьте Controls). Книга и основные интеграции находятся в Core CF4.

Отдельного NTSD-лаунчера нет. Прямой импорт в другие лаунчеры не проверен: они могут требовать ручных загрузок из-за ограничений авторов/CurseForge. Основной поддерживаемый путь этого релиза — CurseForge App на Windows. Не удаляйте моды для обхода ошибки установки.

## Выделенный сервер — Windows и Linux

Скачайте и распакуйте `NTSD-0.1.0-alpha.6-server.zip` в отдельную папку. Нужны **Python 3.10+**, **Java 17**, интернет и уже установленный клиент alpha.6. Установщик использует законно скачанные клиентом общие моды, а не зеркалирует их.

Windows (PowerShell; замените путь на свою папку профиля):

```powershell
py -3 install_server.py --client "C:\path\to\NTSD-client-profile" --java "C:\Program Files\Java\jdk-17\bin\java.exe"
```

Linux:

```sh
python3 install_server.py --client /path/to/installed-client/mods --java /path/to/java17/bin/java
```

Для удалённого Linux-сервера сначала перенесите **свою уже установленную папку mods клиента** на сервер, например через SCP; она нужна только как локальный источник. Скрипт выберет 92 общих JAR, проверит SHA-256 и скачает серверный WorldEdit с официального Modrinth. Клиентские графические моды в сервер не попадут. Forge и Minecraft server runtime скачает официальный Forge installer. Папка назначения по умолчанию — новая `server/`; для другой используйте `--target`. Непустая папка никогда не перезаписывается.

После успешной установки прочитайте https://aka.ms/MinecraftEULA и самостоятельно измените `eula=false` на `eula=true` в `server/eula.txt`, если согласны. Запускайте из `server/` файл `start-server.bat` или `sh start-server.sh`. Java 17 должна быть в PATH; память регулируется в `user_jvm_args.txt`. Сервер создаёт новый мир и использует стандартный online-mode=true; для внешнего доступа настройте server.properties самостоятельно.

В консоли остановка — `stop`; дождитесь сохранения. Для голосового чата нужен UDP 24454, для Minecraft обычно TCP 25565. Установщик не меняет брандмауэр или маршрутизатор. Проверка локального подключения не подтверждает доступность этих портов из интернета. На Linux запуск в этом релизе подготовлен, но нативный Linux runtime-тест не заявлен.

## Обновление без потери сохранений

Остановите игру/сервер через штатное сохранение. Скопируйте **всю папку старого профиля/сервера** в резервное место, включая saves/world, config, defaultconfigs, данные Better Questing, FTB, inventories и serverconfig внутри мира. Проверьте, что копия читается. Импортируйте alpha.6 в **новый профиль**, затем переносите только **копию** своего мира и проверяйте её. Сохраняйте исходник для отката; не открывайте обновлённый мир старой версией.

Для сервера создайте новую установку, перенесите копию папки мира и нужные серверные настройки после остановки. Не заменяйте runtime сборки поверх работающего сервера. Автоматический перенос миров 1.7.10 не поддерживается; их нельзя открывать напрямую в 1.20.1. Terralith в этом релизе отключён.

## Если установка не удалась

Проверьте свободное место, интернет, версию Java и совпадение SHA256SUMS.txt. При ошибке CurseForge повторите импорт в новый профиль; не подменяйте JAR версиями «похожих» файлов. Отчёт об ошибке: https://github.com/BySally/NTSD/issues . Прикладывайте latest.log/crash-report после удаления личных сведений. Ограничения перечислены в KNOWN_ISSUES.md.
