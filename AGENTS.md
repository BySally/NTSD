# NTSD language and maintenance policy

These rules apply to this repository and all future public updates. They reflect
the project owner's approved language policy; do not make global language-policy
changes without explicit owner approval.

1. **GitHub Release descriptions: English only.** Use English headings and link
   labels. Links to Russian documentation are welcome, labeled `Installation (RU)`.
2. **Main GitHub README: English + Russian.** Put English first and provide matching
   Russian information in paired sections or a clearly organized Russian section.
3. **Official NTSD website: English + Russian with a working language switcher.**
   Preserve both translation tables, the RU/EN control and existing language settings.
   Switching language must not reload the page or alter its design and animation.
4. **CurseForge descriptions: English first; Russian translations permitted.**
5. **Technical documentation: English preferred; Russian permitted where useful.**
   Preserve the Russian installation guide `docs/releases/0.1.0-alpha.6/INSTALL_RU.md`
   and keep its public link easy to find. Do not translate legal license texts or
   technical identifiers as part of editorial language work.
6. **In-game localization and quests: unchanged unless separately requested.** Do
   not alter gameplay files, JARs, progression, recipes or worlds for public copy edits.
7. **Communication with the project owner: Russian.**
8. Preserve third-party author credits, license notices and version-matched source
   access. Do not claim NTNH/HBM adaptations are wholly original NTSD materials.
9. Every new release must use accurate working download links. Update the Release,
   README, site config/fallback markup, automated asset detection and player guides
   together. Verify anonymous access and SHA-256. Label installer packages honestly;
   do not call them FULL/offline distributions.
10. Do not make global language-policy changes without explicit owner approval.

For English-only GitHub Releases, use `docs/RELEASE_NOTES_TEMPLATE.md`.
Do not change existing archive bytes, hashes, release tags or user saves merely
to rename an asset or update public documentation.
